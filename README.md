### ⚔️ About Me

**Cybersecurity Researcher · Software Engineer**

I focus on vulnerability research, web application security, reverse engineering, and secure software development.

My work combines offensive security techniques with software engineering and AI to discover, analyze, and understand vulnerabilities in real-world systems.

```text
Research → Analyze → Exploit → Understand → Secure
```

🔭 Currently working on **BugBunty** — a security research and vulnerability triage platform.

🧠 Interested in **Vulnerability Research, Web Security, Binary Analysis, AI Security, and Security Automation.**

### 🧪 Featured Security Projects

#### 🜏 EREBUS — Intelligent Vulnerability Detection

**GNN-based C/C++ vulnerability detection system focused on buffer-overflow discovery.**

* Graph Neural Networks
* GATv2
* Code Property Graphs
* AST / CFG / DFG / CDG
* C/C++ source-code analysis
* AI-assisted vulnerability classification

> Turning source code into graphs to identify patterns associated with memory-safety vulnerabilities.
